#  Laboratório de Ordenação

Site educacional interativo para ensinar **algoritmos de ordenação** no Ensino Médio, com animações passo a passo, comparação de desempenho entre algoritmos e um quiz para testar o aprendizado.

** Acesse online:** [duardo5131.github.io/laboratorio-ordenacao](https://duardo5131.github.io/laboratorio-ordenacao/)



##  O que o site oferece

 **O que é Ordenação** — introdução conceitual ao que é um algoritmo de ordenação e por que ele importa
 **Tipos de Algoritmos** — catálogo com 7 algoritmos: Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort, Heap Sort e Shell Sort
 **Página de cada algoritmo**, com abas para:
   Explicação em linguagem simples
   Animação passo a passo do funcionamento
   Código comentado, sincronizado linha a linha com a animação
   Complexidade de tempo e espaço
   Vantagens, desvantagens e quando usar
 **Laboratório interativo** — o estudante monta sua própria lista (ou gera uma aleatória), escolhe o algoritmo, controla a velocidade e executa passo a passo, acompanhando comparações, trocas e tempo estimado em tempo real
 **Modo de comparação** — executa dois ou mais algoritmos lado a lado sobre a mesma lista, para comparar desempenho diretamente
 **Quiz interativo** — perguntas e alternativas embaralhadas a cada tentativa, com pontuação e opção de refazer
